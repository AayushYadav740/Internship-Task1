SkillCraft Technology Internship Task 01 project – Student Connect Responsive Landing Page!

For this task, I developed a responsive landing page called Student Connect, designed to bring together students across Karnataka by providing valuable information such as:

✅ Details about different engineering colleges

✅ Updates on college events and activities

✅ College cutoff rankings to help students make informed choices


✨ Key Features:

✔ Fully responsive design with a modern layout for both desktop and mobile

✔ Sticky navigation bar with smooth transitions on scroll/hover

✔ Interactive sections for easy access to events and rankings

✔ Simple and clean UI/UX for better user engagement


💡 Learning gained: 

Enhanced my skills in HTML, CSS, and JavaScript while focusing on responsiveness, interactivity, and applying UI/UX design principles.
